# Видеокарты на гибридном ноутбуке

«Системный монитор» показывает Intel отдельной строкой при обнаружении нескольких GPU. В **Настройки → Виджеты → Все виджеты** режим «Авто / Включить / Выключить» управляет строкой Intel. При отключённой или недоступной службе показывается `—`; устаревшие данные не выдаются за актуальные. Компактный размер S и вид macOS сохраняют прежнюю компоновку.

Нагрузка Intel измеряется `intel_gpu_top` системной службой `angelos-gpu-intel.service`. Служба работает от root для доступа к счётчикам GPU; исполняемый файл устанавливается в `/usr/local/lib/angelos/`, данные сохраняются в `/run/angelos-gpu-intel/`. Настройка виджета скрывает строку, но не останавливает службу. Проверка и остановка:

```sh
systemctl status angelos-gpu-intel.service
sudo systemctl disable --now angelos-gpu-intel.service
```

Установка или обновление службы (Arch/CachyOS):

```sh
sudo bash ~/.config/quickshell/angelos/extras/gpu-intel/install.sh
```

Объединённый установщик включает её автоматически при обнаружении гибридной системы с Intel; `INSTALL_INTEL_GPU=0` отключает этот шаг, `INSTALL_INTEL_GPU=1` принудительно запрашивает установку. Если оборудование не обнаружено во время установки, службу можно добавить позднее командой выше.

В **Настройки → Батарея → Видеокарты ноутбука** показано состояние питания устройств из sysfs. Этот просмотр не вызывает `nvidia-smi`. Существующая логика NVIDIA в `gpu-stats.sh` не изменена: она проверяет состояние питания и не опрашивает спящую карту.

Если установка оборвалась, устраните причину ошибки и запустите `./install.sh` снова: pc-kit в форке больше нет, отдельного шага для него не требуется.
