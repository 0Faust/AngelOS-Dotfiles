# Дизайн: автоскрытие дока и нимба в serp (2026-11-14)

## Зачем

В скине serp нижний док с запущенными приложениями и нимб (Halo) всегда
на экране; при окне на всю ширину (как в скриншоте: развёрнутый браузер)
они мешают. Хотим как у мак-дока: уезжают, когда окно занимает почти всю
ширину и касается верха; возвращаются по наведению на свой край.
Верхние острова бара при этом остаются на месте.

## Решения (утверждены опросом)

- Триггер: окно на активном столе касается верха **и** ширина ≥ 90% экрана
  (и хотя бы часть окна видна на экране).
- Возврат: наведение на край — док на нижний, нимб на верхний.
- Прячутся: **нижний док** и **нимб**; верхний бар не трогаем.
- Место: оверлей — `exclusiveZone` дока 0, пока включён автоскрытие.
- Настройка: `wideAutohide` (serp.json), по умолчанию **вкл**, тумблер на
  странице «Док» («Скрывать при широких окнах»).

## Устройство

- `services/Serp.qml`: `cfg.wideAutohide`; `autohideOn` (on && awake && cfg);
  `wideAtTop(name)` — по `Niri.windows` на активном столе:
  `layout.tile_size[0] ≥ 0.9 × screen.width`, верх `pos[1] < 40`
  (гэпы niri 15 + запас нимба), окно не прокручено целиком за край.
- `modules/serp/SerpDock.qml`: `wide = Serp.wideAtTop(screenName)`;
  `shown = !fullscreen && ((!autohide && !wide) || hover || menu.visible)`;
  `exclusiveZone: Shell.dev || autohide || wide ? 0 : slabH + margin`.
  Возврат — существующие edgeStrip/HoverHandler + таймер ухода 600 мс.
- `modules/halo/HaloWindow.qml` (хук в `serp-skin/apply.py`):
  `serpWide = Serp.on && Serp.cfg.wideAutohide && Serp.wideAtTop(name)` →
  в `dodging`; `peekZone` уже включается при `dodging` — наведение на
  верхний край возвращает нимб; `exclusiveZone` нимба 0 при автоскрытии.
- `modules/serp/settings/PageDock.qml`: тумблер «Скрывать при широких
  окнах». `PageBar.qml` не меняется.

## Проверка (сделана)

- Серп включён, firefox `1920×1044` при экране `1920×1080`, `pos y=36`:
  док и нимб уехали, верхние острова на месте.
- `wideAutohide: false` → док и нимб вернулись (скриншоты до/после).
- `qml-check` 825 файлов, 0 ошибок; `kit status` — все патчи ok.
- Возврат по наведению использует уже работающий механизм дока и
  `peekZone` нимба (проверяется движением курсора к краю).
- Golden Gate/Classic не затронуты: всё под `Serp.on`.
